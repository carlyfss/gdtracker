# GDTracker — feature map (frontend)

Top-level routing lives in [`src/App.tsx`](../src/App.tsx). Unauthenticated users are sent to `/login`. After sign-in, users with no games are redirected to `/games/new` (full-screen create); otherwise they land on `/games` to pick or create a game. The main dashboard lives under `/g/:gameId/...` with a shared full-width header, plus a **left sidebar** navigation (icon-only) for Dashboard / Heatmap / Tasks / Configuration; hovering or focusing an icon shows a tooltip label without shifting layout. Inner dashboard pages use flat `.gamePageSection` panels (see [`App.css`](../src/App.css)) inside a vertical `.gamePageStack` where a page has multiple blocks. The Tasks page uses a **left** filter rail and a main column for the table (filters stack above the table on narrow viewports). The Heatmap page uses the same **left** filter rail pattern for event-code filtering and **linked** chart axis range controls (default `[-100, 100]`, step 25) beside the chart (stacked on narrow viewports).

**Shared**

- [`client.ts`](../src/api/client.ts) — shared Axios instance: credentials and CSRF header for Spring Security. After login, call a GET (for example `listGames()`) before POST so the `XSRF-TOKEN` cookie is set; [`GameCreatePage`](../src/pages/GameCreatePage.tsx) primes on mount.
- [`AuthContext`](../src/context/AuthContext.tsx) — session user and `login` / `register` / `logout`.
- [`GameDashboardLayout`](../src/components/GameDashboardLayout.tsx) — dashboard shell, brand row + sidebar (`GameIdProvider`, **`GameThemeProvider`** loads [`getConfiguration`](../src/api/configuration.ts) and applies optional `settings.THEME_COLOR` as `--accent`; cleared when leaving game routes), `.appShell` / `.appMain*` in [`App.css`](../src/App.css)), log out. Main content fills remaining viewport height below the header. [`FeatureTasksModal`](../src/components/FeatureTasksModal.tsx) lists tasks for a feature (same subtask tree, progress, and show/hide controls as the Tasks page) and links to the Tasks page with query params. [`TagTasksModal`](../src/components/TagTasksModal.tsx) lists tasks that share a given tag. [`chipTextColor`](../src/util/chipTextColor.ts) utilities tag pill label contrast.
